Privacidad

PaperEase protege tus datos personales y los utiliza exclusivamente para fines académicos y administrativos.

Uso de datos personales

PaperEase utiliza tus datos para gestionar solicitudes de Bienestar Estudiantil, validar usuarios y dar seguimiento a los servicios solicitados.

La información solo debe ser consultada por personal autorizado para atender tus trámites.

Datos que recopilamos

  • Nombre, apellido y cédula para identificación.
  • Correo electrónico institucional para comunicaciones.
  • Información académica para evaluar elegibilidad en programas.
  • Documentos adjuntos según los requisitos de cada programa.

No compartimos tu información con terceros. Los datos se almacenan de forma segura y se utilizan exclusivamente dentro del sistema de Bienestar Estudiantil de la UTP.
